【開発の経緯】
漫画は好きですが、前から「この人この漫画読んだっけ？」というのを確認するのが難しく
自分が今までに読んだ漫画を共有できれば、と思っていました

【特徴】
・Wikipediaの日本の漫画にある6034タイトルを全て入れています
・読んだ漫画だけでなくおススメの漫画も現状5件まで登録可能
・DBに保存しないのでデータが勝手に何かに使われることは一切ありません。

・今回は漫画ですが、中身のtxtを変えれば好きなジャンルのリストを作る事ができます。
　こういうリストが欲しいというのがあればご連絡ください

【使い方】
１）
漫画をクリック/タップするとステータスが
「未読」「読み途中」「読了」で切り替わります。

２）
読んだことがある漫画を「読了」、
今読んでいる漫画を「読み途中」にしてください

３）
おススメタブの中は好きな漫画を5件まで掲載できます

４）
フッターのQRコードを生成ボタンを押すと
現在の状態を格納したQRコード画像を表示するので
保存してください

５）
SNSなどでアプリのURLとQRコードを公開してください。
#タグもつけてくれるとありがたいです。
（XだとURLがペナルティになる場合は一番上のポストを引用してください）

６）
QRコード画像を保存し、フッターの「QRコード画像を読み込む」ボタンから
アップロード（サーバ上には載りません）すると状態が復元されます。
他の方の画像を復元すればその方の読んだ漫画が分かります。
